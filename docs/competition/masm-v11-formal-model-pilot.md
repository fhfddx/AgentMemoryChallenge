# MASM v1.1 正式模型本机小样本对照

日期：2026-10-03。v1.0 基线 `af9173f939b652443be4f27ef438bb1d6e79e8cf`；
v1.1 候选 `1c7b26a8a0e924cb9343a5afdc47185b25b0841b`。两版分别在本机
`127.0.0.1:18010`、`127.0.0.1:18011` 运行，使用相同的正式 LLM/Embedding 配置、
同一个本地测试数据库、不同用户标识及资产目录。未连接生产数据库、未更改线上服务、
未运行官方评测。测试密钥只用于本机 HTTP 服务；本报告不记录密钥、正文和图片。

共选用预注册合成集中的 7 类，每类 1 例；两版每类的文本、图片和查询相同，标记
后缀按批次随机生成。按顺序分三批运行并逐批删除精确的测试运行；14 个 Add 运行
的数据库行与图片对象清理均报告 `complete=True`。本轮没有运行 100 消息 Top 100
用例，也没有盲测或多随机种子，不能代表官方成绩。

两版顺序运行且供应商请求会波动，不能把差额全部归因于 v1.1，但其额外正式模型
处理路径确实带来值得警惕的写入时延。Embedding 输入量、LLM/图片感知调用数及
费用在当前 HTTP 黑盒脚本中均为 `unavailable`，未估算。

判断：正式模型小样本确认 v1.1 可完成文本、图文、纯图片 Add/Search 与无证据
拒答，且未见这 7 例的标准 Recall 退化；但只在一个多事实类别观察到原子覆盖收益，
写入时延明显增加，成本不可观测。依发布清单，当前**不通过发布门槛**；暂缓并发
