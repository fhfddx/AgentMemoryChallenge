## 2. 方法说明（可供官网表单压缩）

MASM 是参赛方实现的多智能体结构化记忆系统。Add 按原顺序接收文本与内联
Base64 图片，持久化原始消息和图片证据；`gpt-4o-mini` 提取可观察描述、OCR、
实体、关键词和时间关系，`text-embedding-v4` 把文本及图片描述放入统一向量空间。
系统同时保留上下文记忆与来源消息记忆，按同一 `user_id` 做混合召回、一跳关系
扩展、来源对齐去重和词法重排。Search 只返回排序后的记忆证据，不生成最终答案。

v1.1 相对历史 v1.0 的主要变化：

1. 原子写入来源消息粒度记忆，并为父子证据保存来源位置；
2. 图片感知描述进入消息证据与同一文本向量空间，改善跨模态文字查询；
3. 空历史路径跳过没有候选可治理的 Curator 调用，减少常见首写延迟；
4. 收紧 Provider 用量记录、失败分类、正式模型和 HTTPS 配置校验；
5. 保留一个默认关闭的纯文本融合实验开关；正式 v1.1 配置不启用它。

## 3. 模型、依赖与开放性

- LLM：`gpt-4o-mini`，所有正式感知、时序、治理与查询分析组件共用该型号。
- Embedding：`text-embedding-v4`，1024 维；文本和图片可观察描述均使用该型号。
- Reranker：本地词法重排，不调用额外模型。
- 数据库：PostgreSQL + pgvector；图片使用持久化对象卷。
- 代码来源：未直接复制第三方论文仓库代码；通用依赖和许可证见
  `THIRD_PARTY_NOTICES.md`。比赛接口目标来自 AML Cycle 2 官方规则。
- 官网公开规则明确内部架构不限定、原图优先/caption 兼容，并规定上述 LLM 与
  Embedding 型号；最终仍接受主办方的版本、结果与合规复核。
